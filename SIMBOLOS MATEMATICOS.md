# Operaciones aritméticas y álgebra

| Símbolo | Nombre | LaTeX | Uso |
|---------|--------|-------|-----|
| + | Suma | `+` | Operación básica de adición entre números |
| - | Resta / signo negativo | `-` | Sustracción o indicar números negativos |
| × | Multiplicación (signo cruz) | `\times` | Producto entre números, común en aritmética |
| · | Producto (punto) | `\cdot` | Multiplicación en álgebra y vectores |
| / | División (barra) | `/` | División en línea o fracciones simples |
| ÷ | División (símbolo) | `\div` | División tradicional, menos usado en matemática avanzada |
| = | Igualdad | `=` | Indica que dos expresiones son iguales |
| ≠ | Diferente / no igual | `\neq` | Indica que dos expresiones no son iguales |
| ± | Más-menos | `\pm` | Indica dos valores posibles (suma o resta) |
| ∓ | Menos-más | `\mp` | Complemento de ±, indica alternancia opuesta |
| ~ | Equivalencia asintótica | `\sim` | Comportamiento similar o aproximado |
| ≈ | Aproximación | `\approx` | Valores casi iguales, con pequeño error |
| ∝ | Proporcional a | `\propto` | Relación de proporcionalidad directa |
| \| | Tal que / divide | `\mid` | "tal que" en conjuntos, o divisibilidad en teoría de números |
| : | Tal que | `:` | Define condiciones en conjuntos o razones |

# Conjuntos y relaciones

| Símbolo | Nombre | LaTeX | Uso |
|---------|--------|-------|-----|
| ∈ | Pertenece a | `\in` | Indica que un elemento está en un conjunto |
| ∉ | No pertenece a | `\notin` | Indica que un elemento no está en un conjunto |
| ⊂ | Subconjunto propio | `\subset` | A es subconjunto de B pero A ≠ B |
| ⊆ | Subconjunto (o igual) | `\subseteq` | A está contenido en B o es igual a B |
| ⊃ | Superconjunto propio | `\supset` | A contiene a B pero A ≠ B |
| ⊇ | Superconjunto (o igual) | `\supseteq` | A contiene a B o es igual a B |
| ∪ | Unión | `\cup` | Conjunto de elementos en A o B o ambos |
| ∩ | Intersección | `\cap` | Conjunto de elementos en A y B simultáneamente |
| ∅ | Conjunto vacío | `\emptyset` | Conjunto sin elementos |
| ℝ | Números reales | `\mathbb{R}` | Conjunto de todos los números reales |
| ℤ | Enteros | `\mathbb{Z}` | Conjunto de números enteros |
| ℕ | Naturales | `\mathbb{N}` | Conjunto de números naturales (1,2,3,...) |
| ℚ | Racionales | `\mathbb{Q}` | Conjunto de números racionales (fracciones) |
| ℂ | Complejos | `\mathbb{C}` | Conjunto de números complejos |
| ⊔ | Unión disjunta | `\cupdot` | Unión de conjuntos sin elementos comunes |

# Lógica simbólica

| Símbolo | Nombre | LaTeX | Uso |
|---------|--------|-------|-----|
| ∧ | Conjunción (y) | `\land` | Operador lógico AND, ambas condiciones verdaderas |
| ∨ | Disyunción (o) | `\lor` | Operador lógico OR, al menos una condición verdadera |
| ¬ | Negación | `\neg` | Operador lógico NOT, invierte el valor de verdad |
| ⇒ | Implica | `\Rightarrow` | Si P entonces Q, implicación lógica |
| ⇔ | Equivalencia lógica | `\Leftrightarrow` | P si y solo si Q, doble implicación |
| ∀ | Para todo | `\forall` | Cuantificador universal, se cumple para todos |
| ∃ | Existe | `\exists` | Cuantificador existencial, existe al menos uno |
| ⊢ | Deduce sintácticamente | `\vdash` | Relación de deducción formal en lógica |
| ⊨ | Satisface semánticamente | `\models` | Relación de satisfacción o consecuencia lógica |
| ⊥ | Independencia / ortogonalidad | `\perp` | Dependiendo del contexto: contradicción o perpendicularidad |
